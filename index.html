Battleship Game

A Python implementation of the classic Battleship game.

About the Game

Play against the computer to sink all of its ships before it sinks yours! This game includes:

  • Three difficulty levels: Easy, Medium, and Hard.
  • Color-coded game board using the colorama library.
  • Turn summaries to track hits and misses.
  • ASCII art for the welcome screen and game-over messages.

How to Play

Follow these steps to play the game:

  1. Clone the repository: 
    git clone https://github.com/crystal127956/battleship-game.git
  2. Navigate to the project directory: 
    cd battleship-game
  3. Install the required dependencies: 
    pip install colorama
  4. Run the game: 
    python battleship.py

Requirements

  • Python 3.6 or higher
  • colorama library
