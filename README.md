Project Title
Battleship

Description
A Python implementation of the classic Battleship game. Play against the computer to sink all of its ships before it sinks yours!
 
 Features
 - Choose from three difficulty levels: Easy, Medium, and Hard.
 - Color-coded game board using the `colorama` library.
 - Turn summaries to track hits and misses.
 - ASCII art for the welcome screen and game-over messages.
 
 How to run the game
 1. Clone the repository:
    ```bash
    git clone https://github.com/crystal127956/battleship-game.git
 2. Navigate to the project directory: cd battleship-game
 3. Install the required dependencies: pip install colorama
 4. Run the game: python battleship.py
 
 Requirements
 - Python 3.6 or higher
 - [colorama](http://_vscodecontentref_/0) library
 
 How to play
 - Select a difficulty level: Easy, Medium, or Hard.
 - Take turns guessing the location of the opponent's ships.
 - Enter your guess as two numbers separated by a space (e.g., `1 2`).
 - Hits are marked with `X`, and misses are marked with `O`.
 - The first to sink all of the opponent's ships wins!
